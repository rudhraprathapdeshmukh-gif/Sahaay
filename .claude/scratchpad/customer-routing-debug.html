Customer routes are not opening - pages redirect to sign-in or show blank

Current Route Structure

  • / Home
  • /bookings RoleDashboardRouter(customer)
  • /request RoleDashboardRouter(customer)
  • /history RoleDashboardRouter(customer)
  • /profile RoleDashboardRouter(customer)

Root Cause

The RoleDashboardRouter is being called but not properly rendering customer pages.

Problem: The component structure expects nested routes with <Routes> but we're trying to use it as a direct renderer.

✅ Solution

Fix the RoleDashboardRouter to directly return the appropriate component instead of using nested Routes.

This has been updated - the component now calls getSubRoute() directly.
