Platform-Directed Service Flow

Sahaay Service Request Flow

Complete implementation of the platform-directed service request system where customers submit requests to an unassigned provider pool and verified providers claim them.

What We Built

A customer-first service request flow that eliminates provider browsing and selection. Customers specify what they need, when they need it, and how much they're willing to pay. Verified providers then claim requests from the shared pool.

Customer Flow

How customers request services on the new platform-directed model:

1
Category Selection
Choose from 8 service categories: Electrician, Plumber, Carpenter, Painter, Driver, Cleaner, Caregiver, Technician
2
Subcategory Selection
Select specific service (e.g., "Switch & Socket" under Electrician, "Tap & Faucet" under Plumber)
3
Duration & Price
See transparent pricing, choose duration options (for care services), view fee breakdown
4
Schedule & Submit
Pick date/time (30-min slots, 9 AM–5:30 PM), enter address/notes, submit to pool with provider_id: null

Provider Flow

How verified providers interact with the request pool:

A
View Unassigned Pool
See all pending requests with provider_id: null matching their service category
B
Claim Request
Accept a request by updating provider_id to their ID, claiming it from the pool
C
Manage Booking
Continue with normal booking workflow (pending → confirmed → in-progress → completed)
