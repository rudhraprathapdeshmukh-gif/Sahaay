Time Slot Filtering

When selecting today's date, past time slots are automatically filtered out based on current time.

// Only show future time slots for today
const timeSlots = useMemo(() => {
return scheduledDate === today
? generateTimeSlots(true) // filter past slots
: generateTimeSlots(false)
}, [scheduledDate])

7-Day Booking Limit

Maximum booking window reduced from 14 days to 7 days across both components.

// Before: 14 days
maxDate.setDate(maxDate.getDate() + 14)
// After: 7 days
maxDate.setDate(maxDate.getDate() + 7)

Smart Time Validation

Time slot generation checks current hour/minute to filter out past slots.

// Skip past time slots if filtering is enabled
if (filterPast) {
if (hour < currentHour) continue
if (hour === currentHour && minute <= currentMinute) continue
}

User Experience

The booking flow now provides clear guidance and prevents common booking mistakes:

Date Selection

Date picker shows only available dates within the 7-day window, with today as the minimum.

Time Selection

For today's bookings, only future time slots are shown (9 AM to 6 PM in 30-minute intervals).

Help text updated to "Book up to 7 days in advance" to set proper expectations.

Technical Implementation

The solution maintains backward compatibility while adding new validation:

  • Uses React's useMemo for efficient re-computation of time slots
  • Dynamic filtering based on selected date and current time
  • No breaking changes to existing APIs or data structures
  • Works seamlessly with existing booking flow and validation
  • All time slots are generated client-side (9 AM - 6 PM in 30-min intervals)
