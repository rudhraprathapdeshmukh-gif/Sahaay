Sahaay Booking Validation Architecture

Multi-layer protection against past date selection and 7-day booking enforcement
✅ Implemented & Production Ready

The Challenge

Users could bypass HTML date input constraints by manually typing past dates into the date picker. The client-side `min` attribute alone wasn't enough to enforce booking restrictions.

Defense-in-Depth Strategy

4 layers of validation to ensure bookings are only within 7 days in the future:

1. UI Constraints → 2. Client Validation → 3. Server Validation → 4. Database Rules

Validation Layers

1. Client-Side UI Constraints

HTML5 date input with `min` and `max` attributes, plus immediate validation on change.

<input type="date"
min="2026-09-26"
max="2026-10-03"
onchange="validateDate()"
/>
HTML5 Date Input React onChange State Management

2. Client-Side JavaScript Validation

Immediate validation when date changes, plus pre-submission verification.

onChange = (e) => {
const selectedDate = e.target.value;
if (selectedDate < today) {
// Prevent past date selection
setError('Cannot select past dates');
return;
}
}
React State Date Validation Error Handling

3. Server-Side API Validation

Double-check on the server before any booking is created.

// Validate in requestService()
if (scheduledTime <= now) {
throw new Error('Cannot book in past');
}
if (scheduledTime > maxDate) {
throw new Error('Max 7 days');
}

Booking Constraints

Constraint Client-Side Server-Side User Experience
Past Dates Date input min attribute + immediate validation requestService() checks scheduled_at > now Error: "Cannot select a past date"
Future Limit (7 days) Date input max attribute + validation requestService() checks scheduled_at <= now+7d Error: "Only within 7 days from now"
Past Times (Today) Filtered time slots + validation requestService() checks time > now Error: "Cannot select past time slot"
Manual Bypass Prevention onChange event validation + form submission check requestService() catches all invalid requests Multiple fail-safe layers

// Example of complete client-side validation
validateDateSelection = (selectedDate, selectedTime) => {
const now = new Date();
const selectedDateTime = new Date(`${selectedDate}T${selectedTime}`);
if (selectedDateTime <= now) {
return 'Cannot book in the past';
}
const maxDate = new Date(now);
maxDate.setDate(maxDate.getDate() + 7);
if (selectedDateTime > maxDate) {
return 'Maximum 7 days in advance';
}
return null; // Valid selection
}
